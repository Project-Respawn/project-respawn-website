# Ravens-style Starter

Basic static site scaffold inspired by the content structure of the referenced site.

Files created:

- `index.html` — homepage with hero, news, teams, events
- `about.html` — about the club
- `contact.html` — contact page
- `css/styles.css` — site styles with CSS variables (change colors at top)
- `assets/logo.svg` — simple SVG logo

How to use

1. Open `index.html` in your browser (double-click or `Open With Live Server`).
2. Edit `css/styles.css` variables at the top to change the color palette quickly.

Suggested palette improvements are included as a commented example at the top of `css/styles.css`.
