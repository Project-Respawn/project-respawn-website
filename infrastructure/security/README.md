The original `tournaments-Ntgre-final` candidate package is preserved for hash/provenance verification only. Its bootstrap and old policies are historical, not current desired deployment state. Selected historical definitions are retained under documentation evidence, clearly separated from this accepted package.

No document or package here authorizes AWS execution or migration. Use the [accepted checkpoint](../../docs/architecture/phase2a-release1-github-checkpoint-2026-10-04.md) for validation commands and scope.
